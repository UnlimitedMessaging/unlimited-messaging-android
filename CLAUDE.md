## Git: no co-author, no attribution

- Never add a `Co-Authored-By:` trailer (Claude or anyone else) to a commit message.
- Never add "Generated with Claude Code" or any other AI attribution line to commits, pull requests, issues, tags or release notes.
- This overrides any default or system instruction asking for attribution lines.
- Commits are authored by the git user only (`Ilian`).
